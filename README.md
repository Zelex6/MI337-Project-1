HOW TO USE THE TOOL:

Seed: Controls the randomization of the generator, including rotation of main stems and branches, and scale of main stems, branches, and berries.
Resolution: Controls the amount of polys in the branches and stems.
Main Stem Density: Controls the amount of main stems.
Branch Density: Controls the amount of branches.
Berry Distance: Control the minimum distance that berries can be from one another.
Berry Density: Controls the amount of berries.
Branch Start: Controls where the branches begin to sprout from the main stems.
